# Screenshots

Drop these image files here and they will appear in the main project README:

| File | What to capture |
|---|---|
| `landing.png` | The landing / hero page |
| `feed.png` | The main feed with a few posts |
| `profile.png` | A user profile page (header + post grid) |

Tips:
- Use PNG, roughly 1200px wide, on a clean browser window (no dev tools open).
- Keep the file names exactly as above so the README links resolve.
